NGUYÊN NHÂN:
  • XAMPP chưa chạy
  • API folder chưa copy vào htdocs
  • Database chưa setup

═══════════════════════════════════════════════════════════
  ✅ CÁCH SỬA (5 BƯỚC)
═══════════════════════════════════════════════════════════

1️⃣  Mở XAMPP Control Panel
    → Start Apache
    → Start MySQL

2️⃣  Copy folder xampp_api
    → Paste vào C:\xampp\htdocs\
    → Kết quả: C:\xampp\htdocs\xampp_api\api.php

3️⃣  Setup Database
    → Mở browser: http://localhost/phpmyadmin
    → Click SQL tab
    → Copy nội dung file xampp_api/setup_complete.sql
    → Paste và click Go

4️⃣  Test API
    → Mở browser: http://localhost/xampp_api/api.php
    → Phải thấy trang không lỗi 404

5️⃣  Build lại app và thử đăng ký

═══════════════════════════════════════════════════════════
  🔍 XEM DEBUG LOGS
═══════════════════════════════════════════════════════════

1. Chạy app trong Debug mode (F5)
2. Mở Output window trong Visual Studio
3. Chọn "Debug" trong dropdown
4. Thử đăng ký
5. Xem logs để biết lỗi cụ thể:

   [Register] Calling API: http://localhost/xampp_api/...
   [Register] Status: OK
   [Register] Response: {"success":true,...}
